## 4. 链接铁律（2026-09-08 强化，最重要）
- **每条资讯均须设置超链接**，且链接目标须与该条内容 **100% 相关**（点开即见该主题详情）；**默认必须链，仅当摘要完全自包含且确无更优权威源时方可不链**。
- **链接优先级**：① 权威官媒 / 数据源官方发布网站（人行、外汇交易中心、财政部、央行、统计局、海关、外管局、交易所、公司 IR、BLS 等）；② 找不到官方源时，援引主流官媒 / 社媒（新华社、证券时报、财联社、腾讯新闻、每日经济新闻、新浪、网易等）对应该条的具体文章。
- 数据 / 政策类 → 发文或发布机关官网（人行、外汇交易中心、财政部、央行、统计局、海关、外管局、交易所、公司 IR）
- deal / 事件类 → 起源媒体或公司 / 交易所公告
- **严禁链向"财经早餐/陆家嘴早餐"等聚合文首页**，也不得将某条资讯链到与内容无关的门户网站首页（如"美股行情"链中国金融信息网首页）。
- **严禁仅链机构官网根域名或聚合搜索页**（如 `chinamoney.com.cn/`、`stats.gov.cn/`、`safe.gov.cn/`、`nfra.gov.cn/`、`mof.gov.cn/`、`hsi.com.hk/`、`bls.gov/cpi/`、`so.html5.qq.com/...search_news` 等）——点开应是该条对应的**具体文章 / 官方公告 / 数据发布页**。找不到官方具体页时，退到对该条有专门报道的主流媒体具体文章（如证券时报、财联社、新浪、网易对应稿）。
- 链接质量排序：具体文章页 ＞ 权威机构官网具体公告/数据页 ＞ 聚合页；可稳定打开优先。
